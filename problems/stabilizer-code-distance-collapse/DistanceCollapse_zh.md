# 把量子比特换成多能级系统后，码距会保留吗？

**结论。** 有些量子稳定子码即使逐项保持校验对易、继续编码相同数目的逻辑量子单元，码距仍会下降。本文给出了一个公开猜想的反例，复算了两种文献指定的升维算法，并在二维环面上构造了随系统尺寸增大的距离差。英文稿署名 Chatgpt，日期为 2026 年 11 月 27 日。

## 码距在物理上衡量什么

一次泡利错误可以同时作用于多个物理站点。先找出能够避开全部校验、同时会改变所存量子信息的错误，再计数其中最小者作用了多少个站点，这个数就是量子码距。距离为 3 可以纠正任意单站错误；距离为 2 可以探测任意单站错误；距离为 1 则存在连探测都做不到的单站错误。

这里的“升维”有一个具体操作。用整数记录每个站点的位移算符和相位算符的指数，在二能级时对 2 取模，在一个循环四能级系统上对 4 取模。环 $`\mathbb Z/4\mathbb Z`$ 含四个元素。这里使用一个四步循环及其共轭相位所定义的泡利算符。如果一个站点由两个可独立操作的量子比特组成，允许的错误及其权重需要另外指定。

## 三项可以直接检验的结论

| 文献问题或模型 | 实际得到的结果 | 涉及的量词 |

| Gunderman 的下三角整数提升 | 七站点二元码的距离为 3，用原文算法构造的输出在每个循环局域维数 $`m>2`$ 上的距离都是 2（包括所有奇素数） | 固定输入之后，无论把素数取得多大，损失一直存在 |

## 五站点反例为什么成立

把站点命名为 $`a,1,2,3,4`$，取以下三项校验：

```math
Z_a Z_1^2 Z_2^{-2},\qquad X_1X_2X_3X_4,\qquad Z_1Z_2Z_3^{-1}Z_4^{-1}.
```

三项校验的辛内积在整数上就已经为零。它们在 $`a`$ 的相位坐标、站点 1 的位移坐标、站点 3 的相位坐标分别留下可读出的独立系数。这保证它们生成自由秩三的稳定子，符合原猜想的假设。

在二元系统中，$`Z^2=I`$，第一项退化为 $`Z_a`$，站点 $`a`$ 被固定。其余四站由 $`XXXX`$ 和 $`ZZZZ`$ 保护。只动一个数据站点会触发校验，只在 $`a`$ 上施加可通过校验的算符则保持逻辑态；同时作用于两个数据站点的 $`Z_1Z_2`$ 可以成为逻辑错误。因此码距恰好为 2。

在四能级系统中，单独的 $`Z_a`$ 仍与全部校验对易。如果它属于稳定子，第一项的系数必须为 1，而站点 3 又迫使第三项的系数为 0。于是站点 1 会剩下 $`Z_1^2`$，无法消去。单独的 $`Z_a`$ 就成了一个逻辑错误，码距恰好为 1。这是所有较大构造背后的区别：无综合征只说明算符与校验对易；它是否保持逻辑信息，还取决于它能否由校验生成。

## 同一张方格环面上的距离差

Kitaev 环面码是拓扑量子存储的经典模型。边长为 $`L`$ 时，$`2L^2`$ 条边上各放一个量子比特，总共编码两个逻辑量子比特；一个非平凡逻辑错误至少要绕环面一周。[Kitaev](https://doi.org/10.1016/S0003-4916(02)00018-0) · [Dennis 等](https://arxiv.org/abs/quant-ph/0110143)

在同一张格子上，可以取一套有正负号的整数星形校验和面校验，每项都只接触四条边，过一条周期接缝时系数反号。选取生成元时各省去一个星和一个面。在二元系统中，$`-1=1`$，被省去的两项均可由其余校验生成，实际代码正好就是标准环面码。在四能级系统中，若要由其余校验生成被省去的面，系数 1 绕一圈后必须等于 $`-1`$，不可能。因此这个面的四条边已经支撑一个逻辑错误。另一方面，若支撑少于四条边，其非空边图必有至少两个叶子，而仅有一个位置允许没有校验；至少一个叶子会产生非零综合征。这给出精确距离。

```math
d_2=L,\qquad d_m=4\quad(m>2,\ L\ge4).
```

例如 $`L=20`$ 时，两个模型使用相同的 800 个物理站点，各编码两个本地维数相应的逻辑单元。二元系统的距离为 20，所构造的四能级系统为 4。被省略的两个校验是模型定义的一部分；普通的、采用标准定向的多能级环面码也可以保持长程保护。全校验的广义环面和符号扭转已有前人研究，本工作关注具体删项后的码距及其与二元码的直接比较。[Watanabe、Cheng 与 Fuji](https://arxiv.org/abs/2211.00299)

## 结果的分量与证据

该问题横跨代数量子纠错、高维量子信息和拓扑量子存储。对于这两种指定的升维算法，反例表明增大局域维数仍可能无法恢复原距离。环面族进一步说明，这一现象可以持续到任意大的系统尺寸。剩余域猜想本身属于专业研究；有广泛影响的是量子码的距离、局域维数提升和环面码。这一模型已有直接的实验研究，例如 Satzinger 等在超导量子处理器上制备了环面码哈密顿量的基态。本文推导的是理想编码的最坏情况距离，实验误差率、解码器运行效果和容错阈值需要额外分析。[Satzinger 等，Science，2021](https://doi.org/10.1126/science.abi8378)
