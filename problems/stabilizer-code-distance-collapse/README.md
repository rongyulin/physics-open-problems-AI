# Logical distance can collapse under a change of local dimension · 局域维数改变时，量子纠错码距会保持吗？

[English](#english) · [中文](#中文) · [Paper (PDF) / 论文](./DistanceCollapse.pdf) · [Lean proof / 形式化证明](./Lean/DistanceCollapse.lean)

## English

**A quantum code can lose protection even when its lifted checks still commute and it encodes the same number of logical systems.** This project gives a five-site counterexample to the residue-field distance conjecture of Heide Gluesing-Luerssen and Tefjol Pllaha. Its distance is two on qubits and one on cyclic four-level systems. Two further examples test published lifting rules. A family on the square torus shows that the loss can grow with the size of the quantum memory.

### Which problem was open?

The distance of a stabilizer code is the fewest physical sites on which a Pauli error can act while escaping every check and changing encoded information. A zero-syndrome error can be harmless if it is itself generated by the checks. Whether it is so generated can change with the local dimension.

Gluesing-Luerssen and Pllaha asked how the distance of a free stabilizer code over a finite local Frobenius ring compares with its distance after reducing the checks to the residue field. A free code here has independent check generators whose coefficients are uniquely determined. The authors proved that the ring distance is at most the reduced distance, and proved equality when the reduced code is pure, meaning every nonidentity stabilizer acts on at least as many sites as the shortest logical error. **Conjecture 5.5 of their 2017 preprint proposed equality for every free stabilizer code.** [Theorem 5.4, Conjecture 5.5 and Proposition 5.6][glp] · [2019 journal article][glp-journal]

In their seven-site Example 6.1, both distances were three even though the reduced code contained a weight-two stabilizer. Such a stabilizer passes every check and acts trivially on the encoded state. The unresolved step was whether a short logical error over the ring could reduce to a harmless stabilizer over the field while every nontrivial logical error over the field had larger weight. The five-site example below realizes exactly this possibility. [Original seven-site example][glp-example]

### Why five sites suffice

Label the sites *a*, 1, 2, 3, 4. At each site, *X* cyclically shifts the levels and *Z* applies the corresponding phase. Use these three commuting checks:

```math
Z_a Z_1^{2} Z_2^{-2}, \qquad X_1 X_2 X_3 X_4, \qquad Z_1 Z_2 Z_3^{-1} Z_4^{-1}.
```

On qubits, squaring *Z* gives the identity. The first check becomes Zₐ, which fixes the auxiliary site. The remaining four sites have checks XXXX and ZZZZ. Every single-site data error is detected, while Z₁Z₂ is an undetected logical error. The distance is **2**.

On cyclic four-level sites, Zₐ still passes every check. Generating it would require using the first check once, and site 3 forces the coefficient of the third check to vanish. That leaves an uncancelled Z₁² on site 1. Thus Zₐ itself changes the encoded state, and the distance is **1**. The three checks generate a free rank-three module in both cases, so this example satisfies the hypothesis of the conjecture. [Proof, §2](./DistanceCollapse.pdf)

### What happens to proposed lifting rules?

Gunderman claimed that for degenerate codes, a sufficiently large prime local dimension would guarantee that the lifted distance is at least the original one. Islam, Reza and Gunderman gave a related cutoff for sparse CSS codes, whose checks act separately through *X* or *Z*. Testing these claims requires using the actual lifts prescribed in the papers. Each row below uses one fixed binary input and an allowed generator choice for that prescription. Here *m* is the number of levels of a single cyclic physical site.

| Construction | Binary distance | Distance after lifting |
| --- | ---: | --- |
| Seven-site example using Gunderman’s lower-triangular correction | 3 | **2** for every integer *m* > 2 |
| Eight-site example using the centered CSS construction of Islam, Reza and Gunderman, Eq. (13) | 3 | **1** for every integer *m* > 2 |

Both statements include arbitrarily large odd primes. For these inputs and lifts no finite prime cutoff restores distance three. In the eight-site case the binary code corrects any single-site error, while the lift admits a single-site logical error. Other choices of integer lift can preserve distance. [Gunderman, Theorem 15 in the preprint][gunderman] · [Islam, Reza and Gunderman, Lemma 11 and Theorem 12][css]

### Why it matters for a quantum memory

The standard binary toric code stores information in a way that requires a logical string to wind around the lattice. The manuscript chooses integer signs across one periodic seam and omits one star and one plaquette check. Modulo two, the signs coincide and the omitted checks are generated by the others, recovering the ordinary toric code. At every cyclic dimension above two, the omitted plaquette boundary becomes a logical error on exactly four edges. Every check acts on just four sites. [Kitaev’s toric code][kitaev] · [Construction and proof, §5](./DistanceCollapse.pdf)

For every side length *L* ≥ 4, the binary distance is **L**, whereas this signed lift has distance **4** for every *m* > 2. For example, at *L* = 20 both codes use 800 physical sites and encode two logical systems of their respective dimensions. One requires an error on at least 20 sites to change the stored information undetected. The other requires just four.

## 中文

**即便提升后的量子校验仍彼此对易，编码的逻辑单元数也相同，纠错能力依然可能下降。** 本项目用一个五站点反例否定了 Gluesing-Luerssen 与 Pllaha 提出的剩余域码距猜想。它在量子比特上的码距为 2，在循环四能级系统上的码距为 1。项目还分别检验了两种文献指定的升维算法。在一族方格环面码上，这种码距损失还会随量子存储器的尺寸增大。

### 公开问题从哪里来？

量子稳定子码的码距衡量的是：一次泡利错误要同时作用于多少个物理站点，才能逃过全部校验并改变所存的逻辑信息。如果一个算符本来就能由校验生成，那么即使它通过所有校验，对编码信息也无害。改变每个站点的能级数后，同一个算符还是否能由校验生成，正是问题所在。

Gluesing-Luerssen 与 Pllaha 研究了有限局部弗罗贝尼乌斯环上的自由稳定子码，以及把校验约化到剩余域后得到的码。这里的“自由”意味着可以选出一组独立生成元，每个稳定子的系数表示唯一。作者证明了环上的码距不大于约化后的码距，并证明在约化码满足纯性条件时两者相等。这里的纯性指每个非恒等稳定子作用的站点数都至少等于码距。**他们在 2017 年预印本的猜想 5.5 中提出：所有自由稳定子码都应取到等号。** [原文定理 5.4、猜想 5.5 与命题 5.6][glp] · [2019 年期刊论文][glp-journal]

在他们的七站点例 6.1 中，虽然约化码有一个只作用在两个站点上的稳定子，两种码距仍然都是 3。这样的稳定子通过全部校验，对编码态没有影响。尚待确定的是：能否有一个只作用在少数站点上的错误，在环上会改变逻辑态，约化到剩余域后却成了无害的稳定子，而域上的每个非平凡逻辑错误都需要作用在更多站点上？下面的五站点反例实现了这种情形。[原作者的七站点例子][glp-example]

### 为什么五个站点就能给出反例？

把五个站点记作 *a*、1、2、3、4。*X* 表示本站点的循环移位，*Z* 表示相应的相位操作。取三项彼此对易的校验：

```math
Z_a Z_1^{2} Z_2^{-2}, \qquad X_1 X_2 X_3 X_4, \qquad Z_1 Z_2 Z_3^{-1} Z_4^{-1}.
```

对量子比特，*Z* 的平方等于恒等操作，第一项校验就化为 Zₐ，固定了辅助站点。其余四站由 XXXX 和 ZZZZ 保护，每个单站数据错误都能被发现，而双站算符 Z₁Z₂ 可以悄悄改变逻辑态，码距恰为 **2**。

在循环四能级系统里，Zₐ 仍和三项校验都对易。但若想靠校验生成它，第一项的系数必须是 1，而站点 3 又迫使第三项的系数为 0，于是站点 1 残留的 Z₁² 无法消去。单站算符 Zₐ 成了逻辑错误，码距恰为 **1**。三项校验在两种情形下都生成秩三的自由模，满足原猜想的自由性假设。[论文第 2 节](./DistanceCollapse.pdf)

### 两种已有的升维算法会怎样？

Gunderman 提出，对简并码，只要将局域维数取为足够大的素数，提升后的码距就至少等于原码距。Islam、Reza 与 Gunderman 又为稀疏 CSS 码给出了相应的素数阈值，这类码把校验分成只用 *X* 和只用 *Z* 的两组。要检验这些断言，必须使用文献指定的提升构造。下表每一行都固定一个二元输入码，按该构造允许的方式选择生成元，并逐项应用其公式。*m* 表示一个循环物理站点的能级数。

| 构造 | 二元码距 | 提升后的精确码距 |
| --- | ---: | --- |
| 七站点，采用 Gunderman 的下三角修正公式 | 3 | 对每个整数 *m* > 2，均为 **2** |
| 八站点，采用 Islam、Reza 与 Gunderman 的 CSS 系统形公式（13） | 3 | 对每个整数 *m* > 2，均为 **1** |

结论覆盖任意大的奇素数。对于这些输入和指定的提升，素数维数取得再大也不能恢复原来的码距 3。八站点二元码原本可以纠正任意单站错误，提升后却有一个单站逻辑错误连探测都做不到。换用其他整数提升，仍可能保留原码距。[Gunderman 预印本定理 15][gunderman] · [Islam、Reza 与 Gunderman 预印本引理 11 和定理 12][css]

### 对量子存储意味着什么？

标准二元环面码用整张格子保护逻辑信息，最短逻辑错误要绕环面一周。论文为穿过一条周期接缝的校验系数指定符号，同时各省去一个星形校验和一个面校验。在二元系统里正负号相同，被省去的校验也能由其余校验生成，因此得到的正是普通环面码。在每个大于二的循环局域维数上，被省去的那个面的四条边就能支撑一个逻辑错误，而且少于四条边一定不够。每项校验始终只接触四个站点。[Kitaev 环面码][kitaev] · [论文第 5 节的构造与证明](./DistanceCollapse.pdf)

对每个边长 *L* ≥ 4，二元码距为 **L**，而这套带符号提升在每个 *m* > 2 时的码距都为 **4**。例如 *L* = 20 时，两种码都用 800 个物理站点，各自编码两个相应维数的逻辑单元。前者至少需要 20 个站点同时出错才能在校验未察觉时改变逻辑信息，后者只需要 4 个。
